# Quizlet import files

114 cards covering the master study guide for the trunk anatomy, embryology and
birth defects quiz. Every card is `Term<TAB>Definition`, one per line.

| File | Cards |
|---|---|
| `all-cards.txt` | 114 — the whole guide as one set |
| `module-1-trunk-terminology.txt` | 32 |
| `module-2-first-week.txt` | 19 |
| `module-3-weeks-2-to-8.txt` | 28 |
| `module-4-musculoskeletal.txt` | 13 |
| `module-5-birth-defects.txt` | 22 |

Import the combined file for one big set, or the five module files for five
smaller sets you can drill one at a time.

## How to import

1. On quizlet.com, click **+** then **Study set**.
2. Click **Import** (under the title box, "Import from Word, Excel, Google Docs, etc.").
3. Paste the contents of the file.
4. Set **Between term and definition** to **Tab**.
5. Set **Between cards** to **New line**.
6. Check the preview, then click **Import**.

The Quizlet mobile app has no import screen. Paste on the web, on a phone
browser if needed, and the set syncs to the app.
