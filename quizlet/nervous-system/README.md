# Nervous system: Quizlet import files

133 cards from the master study guide for Module 1 (Introduction to the
Nervous System) and Module 1 Ch. 2 (Development of the Nervous System). Every
card is `Term<TAB>Definition`, one per line.

| File | Cards |
|---|---|
| `all-cards.txt` | 133 — the whole guide as one set |
| `part-1-organization-and-cells.txt` | 88 — objectives 1.1 to 1.7 |
| `part-2-development.txt` | 45 — objectives 2.1 to 2.4 |
| `exam-alerts.txt` | 29 — only the cards from the EXAM ALERT boxes |

## How to import

1. On quizlet.com, click **+** then **Study set**.
2. Click **Import** (under the title box).
3. Paste the contents of the file.
4. Set **Between term and definition** to **Tab**.
5. Set **Between cards** to **New line**.
6. Check the preview, then click **Import**.

The Quizlet mobile app has no import screen. Paste on the web, on a phone
browser if needed, and the set syncs to the app.

This is a separate deck from the trunk anatomy and embryology cards in
`quizlet/`.
